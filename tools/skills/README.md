# tools/skills — 可移植技能资产

本目录放「随仓库走」的 Kimi Code 技能包：权威副本在仓库，使用机器上把对应文件夹
复制到用户技能目录 `C:\Users\<用户名>\.kimi-code\skills\<技能名>\` 即完成安装
（Kimi Code 启动后自动识别）；不安装也可直接按各技能 SKILL.md 里的命令当脚本用。

- `pk-watermark-test-report/`：PK 赛（离线去水印评比）批次测试报告固定评定技能，
  含评定规程、参数化报告生成器与配置模板。保留理由：跨轮次、跨机器固定评比口径，
  属参数化报告生成器（见 AGENTS.md 第 11 节分类）。

新增技能：建子目录、放 SKILL.md（带 name/description 前言）与脚本，并在本 README 补一行说明。
