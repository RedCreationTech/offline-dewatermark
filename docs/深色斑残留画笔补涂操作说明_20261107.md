# 提示词去水印后"深色斑残留"的画笔补涂操作说明

- 日期：2026-11-07
- 适用版本：提示词定位功能上线后（main ≥ 4867598）
- 典型场景：`real_010`（斜向黑字"内部演示稿"）按提示词处理后，水印与正文最密集交叠处留下一小块深色斑

## 背景（为什么会有这个斑）

那一块是**黑水印笔画压在黑文字上**的最密交叠区，被压住的原始文字像素在图片里已经不存在。程序已经把这块选进了修复范围，但 LaMa 修复模型无法凭空重建文字，只能涂出深色纹理——**这是修复模型的重建极限，不是漏选**。对这种"紧凑的一块斑"，用笔刷把选区补实再处理一次，LaMa 就能填干净（周围是大面积纸面，重建容易）。

## 操作前确认

1. 该页已经用提示词定位跑过一遍（图片列表里状态为"待复核"或"质量未通过"都行，必须有处理结果才能编辑）。
2. 当前批次参数保持：找水印方式＝提示词定位、处理方式＝按笔画（补涂与这些参数无关，不用改）。

## 逐条操作

1. 在左侧**图片列表**点选要修的页（如 `12 real_010·第1页`）。
2. 点预览区上方的**「编辑水印选区」**按钮。画布自动切到"原始图片"视图，**青色**高亮显示当前完整选区（编辑态用青色而不是红色：红色叠加在黑色水印笔画上几乎看不见，青色在白底和黑笔画上都清楚，每一笔涂到哪里一目了然）；上方出现笔刷工具条（添加 B / 擦除 E / 笔刷 N 像素 / 撤销笔画 / 重做）。
3. **视图可以自由切换**：「原始图片」「水印选区」「处理结果」三个视图都能落笔（修复残留只存在于结果图里，**在处理结果视图上直接涂最顺手**——坐标与原图一一对应，处理时仍从原图重修复）；只有「拖拽对比」不能描涂（底部状态条会提示切回）。
4. 确认工具条里**「添加 B」**处于按下状态（默认就是）。
5. 按斑的大小调**笔刷直径**：斑大约 2 厘米见方时填 **100–150 像素**（200dpi 渲染页）；小斑 40–80 即可。宁可一笔涂完，不要来回碎涂。
6. 滚轮放大到斑清晰可见（"画笔放大镜"默认开启，落笔处有局部放大），把画布平移到斑处（空格＋拖动）。
7. 在**深色斑上按住左键涂满整块斑**，边缘超出斑约 5–10 像素；松开即完成一笔，红色选区随之增加。
   - 涂错了：切换**「擦除 E」**把多涂的部分擦掉再切回"添加"；或点**「撤销笔画」**（快捷键 Ctrl＋Z）回退整笔。
8. 切到**「水印选区」**视图核对：红色应完整盖住深色斑；**确认没有涂到斑周围的正文文字**（涂到正文会把那部分文字也重建掉）。
9. 点**「按当前选区处理」**。程序从原图按完整选区重新处理该页：原有自动选区沿用各自修复路线，你新涂的斑块走 LaMa。等待状态栏完成（单页约 10–20 秒，不再调用提示词模型）。
10. 看**「处理结果」**或**「拖拽对比」**：深色斑应消失，周围文字无新变化。
    - 不满意：点**「撤销本次处理」**回到补涂前的结果，调整笔刷后重涂再走第 9 步。
    - 中途想放弃编辑：点**「取消编辑」**，图片和已存结果都不变。
11. 合格后继续其他页；最后**「导出结果」**正常导出（导出会保留自动基线与这次人工辅助的记录）。

## 验证要点（逐条打勾）

- [ ] 补涂后深色斑消失，无新的灰/黑色块；
- [ ] 斑周围的正文行与处理前一致（拖拽对比核对）；
- [ ] 「水印选区」视图里红色选区仍只在合理范围（没有大片误涂）；
- [ ] 撤销本次处理后再重做一次，结果一致（可重复）；
- [ ] 导出目录中该页 manifest 的 `processing.human_assistance` 记录了这次编辑。

## 故障排查

- **按住左键涂不上青色**：只有「拖拽对比」视图不能描涂；「原始图片」「水印选区」「处理结果」都可以，切过去再涂（底部状态条会提示）。
- **「编辑水印选区」按了没进编辑**：该页还没有处理结果（提示词或自动跑过一遍才行）；或当前有队列/辅助任务在运行，等它结束。
- **工具条里"添加 B / 擦除 E"灰色**：不在编辑状态，重新点「编辑水印选区」。
- **涂完点「按当前选区处理」没反应**：选区没有变化（未新增笔画）时按钮不可用；先确认涂过至少一笔（「撤销笔画」可回退的笔数 > 0）。
- **处理后斑还在**：笔刷太小或只涂到斑边缘。撤销本次处理，笔刷调大 30–50 像素，把斑整体盖住再处理。
- **处理后留下淡淡的文字轮廓（勾勒残留）**：这是 LaMa 顺着 mask 边缘的抗锯齿光晕"续画"了原笔画形状。**笔刷再放大一圈，把残留连同周围 20–40 像素的干净纸面一起涂进去**——让 mask 边缘落在均匀纸面上，模型就无结构可续。可重复"编辑→加涂→处理"几轮，每轮都从原图重修复，只会更好。
- **黑斑没了但底图发灰/有噪点**：LaMa 按周围统计分布生成纹理，黑字环绕下填出来偏灰。现在**笔刷涂到均匀纸面上时程序会自动改用周围纸面中位色均匀填补**（纯白即纯白），不再经过 LaMa；重新"编辑→加涂→处理"一次即可得到干净底图。只有笔画压在文字/图案上（周围不均匀）时才仍走 LaMa。
- **处理后周围文字花了**：涂到了正文。撤销本次处理，用「擦除 E」把超出正文的笔画擦掉，只留斑本体再处理。
- **处理后顶部/边缘多出黑条、黑斑**：笔刷扫到了页面顶边或边缘（120px 笔刷一笔很宽），该片被选进范围后 LaMa 整块重绘成了黑色。撤销本次处理 → 切「水印选区」视图找到顶部多出来的红色条带 →「擦除 E」把它擦掉（只留真正要修的斑）→ 重新「按当前选区处理」。预防：落笔前先看光标位置， strokes 从斑内部起笔，不要从页面外拖进来。
- **撤销一次后黑条还在**：「撤销本次处理」每次只回退一步；若涂过多次就多点几次，直到质量检查里"处理模式：人工辅助"行消失。想彻底重来可点「重新自动识别当前图片」（按当前提示词重新定位重跑，丢弃全部补涂）。

## 注意事项

- **不要整行涂**：若把整行文字涂进选区，那行文字会被重建成纸面纹理（不可逆）。只涂斑块本身＋少量边缘。
- 一笔一笔来：每笔之间可以切视图核对，最后一笔优先。
- 补涂只影响当前页；批内其他页不受"编辑选区"模式影响（切页未处理的编辑自动丢弃）。
- 若整页大面积残留（不只是斑），不要用画笔硬涂——回到参数面板检查提示词是否覆盖全部水印内容，或改用"整框重绘"。
