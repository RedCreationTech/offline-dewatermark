## 共性背景：提示词链路当前实际执行步骤（基线 a0c36af）

1. **模型定位**：`tools/wevisone_server.py`（WeVisOne-VL-2B，独立 venv）按提示词对整图分割，返回实例框（像素坐标）；温度 0，输出确定。客户端 `wm/wevisone_client.py` 管理常驻/按需进程。
2. **框内选区提取**（`wm/prompt_detect.py::locate_strokes`，按笔画方式）：
   - 每个框外扩 64px 取 crop；OCR 正文区作为保护区（`protected`），`grow_domain = 框内 & ~保护区`（matte 存在时再 ∩ matte 支撑）；
   - 种子 = 检测器 alpha ≥ 8% ∩ grow_domain；种子空时用框内对比响应前 15% 兜底；
   - `recall._pixel_strokes` 由种子做局部对比证据的连通生长，只保留含种子的连通域；
   - **尺度通道**：全页实心墨迹（纸面亮度−50）→ 9px 椭圆开运算移除细正文行 → 只保留与模型框相交且近黑实芯的大连通域（收回巨大不透明笔画及伸出框的延伸）；
   - 两路合并，选区严格限框内（尺度通道可及框外延伸）。
3. **闸门**（`wm/pipeline.py::_process_one`）：空选区/低置信/重绘面 >25% 一律不动原图。
4. **修复**（`wm/repair.py` → `wm/lama.py::repair_with_lama`）：提示词图层 `repair_mode='inpaint'` → **整个 footprint 一次性送 LaMa**（ONNX，512 分块、按包围盒+上下文裁切）。
   - **关键点：此路径没有透明度公式反解**。alpha_unmix 只用于有可测叠加模型的路由（periodic_overlay、document_overlay 等），提示词图层没有 veil 参数，不会走反解。
5. **判定与导出**：四条件判定、质量未通过标记人工；导出保留证据。

### 条目 #001 · 2026-11-09 · real_010 第1页：LaMa 黑斑 + 交叠文字恢复不理想

- **样本**：`data/watermark_regression_min_v1/inputs/real/real_010.pdf` 第 1 页（1654×2339 @200dpi）
- **提示词**：`斜向黑字"内部演示稿"`　**参数**：按笔画、文字识别☑、阈值 8%、外扩 0
- **现象**（当前基线复现）：
  1. 模型框正确（框住整条斜向水印）；
  2. 结果图"预计工时 3 小时"右上方出现一块**深色污斑**（LaMa 填充产物）；
  3. 水印与正文行交叠处的文字被抹掉后以**灰色平滑纹理**重建，不可读（"恢复不理想"）。
- **复现**：GUI 提示词定位跑该页；或 `tools/run_prompt_feature_selftest.py` 的真实链路。
- **现状逐环节分析**（含实测数据）：
  1. **选区覆盖缺口**：以方向带通近似水印墨迹真值，当前选区仅覆盖斜向墨迹 **21.5%**（26,209/33,399 像素未选中）。缺口成因：OCR 保护区把压正文的笔画整片挡在 grow_domain 外；尺度通道受 9px 开运算与"近黑连通大块"条件限制，弧形/短促笔画段被切碎丢弃。
  2. **黑斑成因**：被选中的、坐落在纯白纸面上的笔画大块送 LaMa 后，模型按周围统计分布生成填充——大片纸面被填成灰黑色调（且该块紧邻日期/正文，上下文偏暗），形成污斑。黑斑所在处选区无漏（是"修得脏"不是"没选到"）。
  3. **交叠文字恢复**：交叠处的原始文字像素已被水印覆盖、信息不存在；LaMa 无法凭空写出字形，只能生成平滑纹理 → 模糊不可读。**纯 LaMa 结果，无公式反解参与**。
  4. 未选中墨迹（约八成）在原图保持不动；在"全 LaMa 暗色"版本里它们被周围暗色填充低对比掩盖（观感尚可），这是当前基线"反而最好看"的原因。
- **已尝试方案与结论**（均已回滚，记录于流程图 V1.32）：
  | 方案 | 结果 | 结论 |
  |---|---|---|
  | 自动纸面直填 `9f02d1a` | 纸面变白、黑斑消除，但约八成未选中墨迹高对比暴露 | 单独上"更干净"反而暴露覆盖缺口 |
  | 交叠去除开关 `e925fb1`（默认开） | 水印全覆盖去除，但笔画扫过的文字段成片擦除 | 彻底但伤文字，用户否决 |
  | 方向带通通道 | 织物页精确率 0.90→0.10 崩坏；弧形笔画覆盖不足 | 未入库即回滚 |
- **可行方案**（按投入排序，供评审选择）：
  1. **现状维持 + 笔刷收尾**（零开发）：黑斑与个别残留用笔刷补涂（纸面中位色填补已生效，补涂无灰底）。适合该页这类"一页一两处"的场景。
  2. **纸面直填 v2（条件强化版）**：只在"整块选区周边环带完全无文字"时才直填（比 9f02d1a 的逐像素判定更保守），把黑斑消掉而不改变交叠区域行为；未选中墨迹的观感问题仍在。
  3. **覆盖补强 + 文字代价显式化**：将 `e925fb1` 的交叠去除开关恢复但**默认关闭**，与方案 2 组合：默认=当前观感，按需对"水印必须无残留"的批次开启。
  4. **长期**：换更强的本地修复模型（与 LaMa 同 ONNX 接口即可替换），或文本感知重建（需训练，本机不具备条件）。
- **验收口径建议**：以本页为基准样例，指标 = 斜向墨迹覆盖率（方向带通参照）、黑斑区平均灰度（≥245）、交叠处文字可读性（人工评级）；任何候选方案须同时报 core_009（织物页）与 real_001/008 的回归。
- **状态**：维持基线（条目待评审选定方案后更新）。
