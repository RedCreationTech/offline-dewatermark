# 仓库内容与本地资料说明

版本：V1，更新日期：2026-11-02。

## 仓库保留什么

- `wm/`：应用、检测修复流程及必要资源。
- `tests/`：工程测试，个人外部修图助手测试除外。
- `tools/`：通用维护、评测、报告生成与研究工具，个人助手和投标工具除外。
- `config/`：回归规则、预定门槛和退役样本记录。
- README、安装与资源说明、项目架构及长期处理流程。

工程测试与回归规则继续保存。移除报告不表示删除测试样本、改变质量门槛或证明算法更好。

## 什么只留本机

| 范围 | 内容 |
|---|---|
| `out/` | 测试报告、输入输出、日志、每轮实验、封存基线及清理记录 |
| `docs/` 中非明确允许的文件 | HTML 报告、样本图片、内部分析、历史记录与标注说明 |
| `proposal/`、`tools/build_tender_*` | 投标方案和生成材料 |
| `下一步优化任务.md`、`visualizations/` | 内部任务草案与个人讲解素材 |
| `tools/kimi_image_*`、`tests/test_kimi_image_tools.py` | 个人外部修图辅助工具、依赖和测试 |
| `.kimi-code/`、`.qoder/`、`.codex/`、`.claude/` | 个人 Agent 配置 |
| `.chart-data-*/`、`.regression-control/` | 本机图表快照与基线指针 |
| `.env`、`.env.*`、编辑器目录、缓存 | 本地配置和开发状态；无真实凭据的示例配置可入库 |
| `data/`、`models/`、`.venv/` | 数据、模型及本机运行环境，另行准备 |

文档允许清单为 `docs/knowme.md`、`docs/去水印处理流程图.md` 和本文。需要加入新的通用说明时，先审核内容，再显式调整 `.gitignore`，不要强制加入整个报告目录。

本地报告目录入口为 `out/水印验证报告总目录.html`。该文件及其引用资料只在拥有相应本地文件时可用，不作为克隆仓库后的必备入口。通用报告生成脚本仍可生成这些文件，忽略规则会阻止普通提交再次收录。

## 本次清理的边界

本次以普通提交取消追踪，所有被取消追踪的本地原件保留。新仓库当前版本不再携带这些资料，但已经发布过的旧提交和资源标签仍可能包含旧文件；本次没有重写历史，也不声称隐私资料已从所有历史版本彻底清除。

原仓库和原 Release 不改动。Release 说明、附件不会随 Git 分支或标签自动复制。当前资源下载继续使用资源说明中的原 Release 链接。

本机 `refs/codex/` 检查点没有推送到新仓库。普通分支清理不会删除这些本地检查点；不要对包含本机内部引用的工作仓库执行镜像推送。

## 本地备份与质量口径

换电脑时另行备份所需数据、模型、输入导出、完整封存结果及方案原件；密钥和个人配置单独管理。本机绝对路径不应写进共享工具，语料和报告字体分别用 `WM_CORPUS_FONT`、`WM_REPORT_FONT` 显式指定。

本次没有调整检测、修复、路由、参数、样本或基线。逐张及跨样式效果不在本次重新测量；未完成完整发布放行与独立泛化验证，仓库清理不构成效果提升或质量合格的证据。
