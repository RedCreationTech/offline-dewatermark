01准备基础工具

按 Windows 或 macOS 选一组命令。主程序沿用 Python、PySide6、OpenCV 和 ONNX Runtime，项目版本以团队指定的 Git 提交为准。初次取代码、安装依赖和下载资源需要联网。

  • Windows x64 示例。安装 Git for Windows、64 位 Python 3.14 和 Microsoft Visual C++ x64 运行库。执行 git --version 和 py -3.14 -V 确认安装。
  • macOS 14 或以上 · Apple 芯片示例。在「终端」执行 git --version；若没有 Git，执行 xcode-select --install 安装命令行工具。安装 Python 3.14 后执行 python3.14 -V，并用 uname -m 确认终端架构为 arm64。

03安装桌面程序依赖

在目标电脑新建 虚拟环境，先按仓库的精确锁定清单安装。每次新开终端时，重新设置 Windows 的 $py 或 macOS 的 py 变量。

Windows PowerShell

$env:PYTHONUTF8 = "1"
py -3.14 -m venv .venv
$py = ".\.venv\Scripts\python.exe"
& $py -m pip install --upgrade pip
& $py -m pip install -r requirements.lock
& $py -m pip check

macOS 终端

python3.14 -m venv .venv
py=.venv/bin/python
"$py" -m pip install --upgrade pip
"$py" -m pip install -r requirements.lock
"$py" -m pip check

若无法按锁定清单安装，可在新建的干净环境中把安装命令末尾改成 -r requirements.txt，并记录报错和实际版本。两份清单都失败时，先核对 Python 版本、系统架构和缺失包。

两套步骤都直接用 Python 模块入口，PySide6 随依赖清单安装。

04下载、校验并放置资源

从项目 Release 下载两个数据包、一个模型包和 SHA256SUMS.txt，放在仓库同级的 wm-resources 目录。核对校验值后，将三个 ZIP 分别解压到同一个空白项目根目录。

项目资源 Release · 校验值文件

Windows PowerShell · 第 2 行输出需和校验值文件比对

$download = "..\wm-resources"
Get-FileHash "$download\*.zip" -Algorithm SHA256
Expand-Archive "$download\data_bundle_part1_of2.zip" -DestinationPath . -Force
Expand-Archive "$download\data_bundle_part2_of2.zip" -DestinationPath . -Force
Expand-Archive "$download\model_bundle.zip" -DestinationPath . -Force

macOS 终端 · 首行校验通过后再执行解压

(cd ../wm-resources && shasum -a 256 -c SHA256SUMS.txt)
unzip -o ../wm-resources/data_bundle_part1_of2.zip -d .
unzip -o ../wm-resources/data_bundle_part2_of2.zip -d .
unzip -o ../wm-resources/model_bundle.zip -d .
资源放置位置或用途
data_bundle_part1_of2.zip、data_bundle_part2_of2.zip合并为根目录下的 data/。两份都是普通 ZIP。
model_bundle.zip解压为 models/。确认有 models/inpainting_lama_2025jan.onnx。
最新固定测试集与应用测试图从团队当前工作机或备份取得相匹配的 data/。提示词首轮还需准备此前的 9 张斜向平铺文字图。

Release 是 10 月 27 日的数据快照。若要对当前代码执行固定集校验，需要同步团队现行数据及其清单。若校验不通过，先核对数据来源和版本。

05离线启动并验证现有功能

主程序先用项目默认的 CPU 路径启动。下面先检查依赖、磁盘上的 LaMa 权重和模型加载，再打开桌面程序。输入路径含空格或中文时用引号包住。

Windows PowerShell

$env:HF_HUB_OFFLINE = "1"
& $py -c "import numpy, cv2, fitz, PySide6, onnxruntime; from pathlib import Path; from wm import lama; p=Path('models/inpainting_lama_2025jan.onnx'); assert p.is_file(), p; assert lama.is_available(), 'LaMa load failed'; print('app dependencies and local LaMa OK')"
& $py -m wm.app

macOS 终端

export HF_HUB_OFFLINE=1
"$py" -c "import numpy, cv2, fitz, PySide6, onnxruntime; from pathlib import Path; from wm import lama; p=Path('models/inpainting_lama_2025jan.onnx'); assert p.is_file(), p; assert lama.is_available(), 'LaMa load failed'; print('app dependencies and local LaMa OK')"
"$py" -m wm.app

窗口打开后导入一张测试图，执行一次自动识别与修复，检查结果；然后用画笔补一处选区、用橡皮擦撤回一处，重新修复并确认预览。留一张原图与导出结果作为本机验证记录。

固定数据校验和单图启动自测

固定集准备好后运行第一条。第二条执行一张内置样本的无窗口处理，成功时会输出 smoke ok。

Windows PowerShell

& $py tools/run_min_regression.py --validate-only
$env:QT_QPA_PLATFORM = "offscreen"
& $py -m wm.app --smoke

macOS 终端

若检查找不到 LaMa，先确认没有多套一层解压目录。中文合成样本缺字时，按仓库说明设置 WM_FONTS_DIR；重建原语料时保留原字体。

06准备 WeVisOne-VL-4B 提示词实验

这套环境用于单图定位和掩码实验。4B 的模型与掩码解码器权重合计约 9.7 GB，另需预留 PyTorch 依赖、下载缓存与实验结果的空间。主程序和模型实验分别使用 Python 3.14 和 Python 3.12，避免项目与上游不同的 NumPy 版本装到同一环境。

Windows PowerShell / macOS 终端 · 获取此前实验使用的上游源码版本

git clone https://github.com/Tencent/WeVisOne-VL.git out/third_party/WeVisOne-VL
git -C out/third_party/WeVisOne-VL checkout 9a6bcd85404505df0d05cfb5d97512ccacf35dee

先从本机系统对应的 Python 下载页安装 Python 3.12，与主程序的 Python 3.14 并存。

Windows PowerShell · 创建模型环境

py -3.12 -m venv out\third_party\WeVisOne-VL\.venv
$wv = ".\out\third_party\WeVisOne-VL\.venv\Scripts\python.exe"

macOS 终端 · 创建模型环境

python3.12 -m venv out/third_party/WeVisOne-VL/.venv
wv=out/third_party/WeVisOne-VL/.venv/bin/python

先用上游样图验证离线掩码

把下方代码以 UTF-8 保存为项目根目录的 out/试跑_wevisone.py。它用提示词 sofa 跑上游示例，检查能否加载本地权重并输出掩码。如需复跑，把脚本里的输出目录换成新名称。

Python · 单图分割自测

from pathlib import Path
import sys

import torch
from PIL import Image
from wevisone_vl import WeVisOneVL
from wevisone_vl.visualization import save_result

source = Path("out/third_party/WeVisOne-VL/demo/examples/images/livingroom.jpg")
output = Path("out/WeVisOne-4B环境检查_01")
output.mkdir(exist_ok=False)

image = Image.open(source).convert("RGB")
device = sys.argv[1]
dtype = "float32"
if device == "cuda:0":
    dtype = "bfloat16" if torch.cuda.is_bf16_supported() else "float16"
model = WeVisOneVL("models/WeVisOne-VL-4B", backend="transformers", device=device, dtype=dtype)
result = model.predict(image, task="segmentation", query="sofa")
save_result(output, image, result)
print("mask_count =", len(result.masks))

Windows PowerShell · 断开模型联网下载

$env:HF_HUB_OFFLINE = "1"
& $wv out/试跑_wevisone.py cuda:0

macOS 终端 · 断开模型联网下载

HF_HUB_OFFLINE=1 "$wv" out/试跑_wevisone.py cpu

打开 out/WeVisOne-4B环境检查_01/overlay.png 和 masks/，确认沙发选区可见。然后用同一入口换成项目首张斜向文字图与水印描述，逐张记录漏选、误选与字洞。选区通过检查后，再接入按掩码修复和桌面入口。
